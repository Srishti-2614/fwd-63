About

Mess Feedback and Complaint is a simple place for students to report problems with the hostel mess and to see whether they have been fixed.

Complaints can be anonymous. Each one is marked Open until the mess committee resolves it.

Built as a Fundamentals of Web Design project by Srishti Dahiya, Section D, using HTML, CSS and JavaScript.
