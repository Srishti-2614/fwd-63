About

SAU Mess Portal helps students of South Asian University, Delhi, share feedback on hostel mess meals and report problems that the mess committee can track to resolution.

Students rate a meal with one tap, file complaints (anonymously if they prefer), and see on the dashboard how each meal and category is doing.

The octagon in the logo mark is a nod to the eight SAARC member countries that SAU serves. This is a student project and not an official SAU website.

Built by Srishti Dahiya, Section D, for Fundamentals of Web Design using HTML, CSS and JavaScript.
